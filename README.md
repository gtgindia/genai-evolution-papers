# Generative AI Evolution: From Attention to Agents

A visual, paper-by-paper guide to the ideas that shaped modern generative AI, from the Transformer through BERT, retrieval, image generation, alignment, and reasoning models.

## Start here

Open [`genai_evolution/presentation.html`](genai_evolution/presentation.html) in a modern browser to explore the interactive presentation. It runs locally without a build step or external dependencies. Use the arrow keys or Space to move between slides, **O** to open the overview, **F** for fullscreen, and **1–4** to jump between acts. Paper slides link to their detailed notes.

## What's included

- `genai_evolution/presentation.html` — the interactive presentation.
- `genai_evolution/00_genai_evolution_story.md` — the narrative connecting the papers.
- `genai_evolution/` — detailed notes for the papers featured in the presentation.
- `study_guide/` — shorter guides for reviewing key papers.

Paper PDFs are intentionally excluded from Git; the Markdown notes and presentation remain available here.
